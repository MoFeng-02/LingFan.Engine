# Fonts/——字体名注册表

把字体文件放进本目录即完成注册：**字体名 = 文件名去扩展名**（`楷体.ttf` → 字体名 `楷体`）。

- 参与注册的扩展名：`.ttf` / `.otf` / `.woff` / `.woff2`（其余文件忽略）。
- 引用：故事层只写字体名字符串——`{font=楷体}` 行内标签或 `say` 行参 `font: "楷体"`。
- 守门分两档：构建期对静态引用 fail-closed（未注册名 stories:build 直接报错）；
  运行期对动态拼接名回退默认字体并输出诊断（`configureStoryFonts` 宿主装配）。
- 宿主自动为本目录的字体注入 `@font-face`（Vite 构建期扫描），无需手写样式。
- 建议文件名只用字母数字、中文与连字符，避免空格等需转义字符。
