---
title: 回溯与历史
description: 引擎在等待点建检查点，玩家回退时回到上一个检查点重新执行。重选会砍掉后面的历史，回溯也会打断正在跑的小游戏。
---

玩家点「回退」，故事退到上一屏。这不是把界面往回滚——引擎是真的回到那一条命令，从那里重新执行一遍。所以变量、随机数、舞台上的元素都会跟着回去。

## 检查点建在哪

只有等待点会建检查点。命令跑完就往下走的那种不留痕。

| 命令 | 检查点 |
|---|---|
| `say` | 有 |
| `menu` | 有 |
| `wait` / `pause` | 有 |
| `input` | 有 |
| `cutscene` | 有 |
| `minigame` / `interaction` | 有 |
| `jump` / `navigate` / `call` / `return` | 无 |
| `video` | 无（不阻塞，故事继续走） |

`say` 的检查点在上屏那一刻拍下来，但等你离开这一屏才入档。这样「所见即历史」：回退之后再前进，能回到你刚才看到的那句话。

`type=menu` 和 `type=ui` 的列完全不参与历史——不建检查点，也不进历史列表。做暂停菜单和状态面板时用它们，玩家的回溯记录里就不会多出这些临时界面。

## 回退一步

```ts
engine.back();
```

停在某个画面上按回退，当前画面会先入档，然后退回它之前的那一个。已经退到最早保留的检查点还按，报 `history-empty`「已回溯到最早保留点」。

想自己判断能不能退，读两个数：

```ts
engine.historyLength(); // 已归档的检查点数量
engine.historyCursor(); // 当前光标，回溯后小于 historyLength() - 1
```

## 退到指定位置

```ts
engine.rollbackTo(12);                                   // 第 12 个检查点（从 0 数）
engine.rollbackTo({ columnId: "chapter_two", index: 8 }); // 这个坐标之前的最近检查点
```

给下标就是精确定位。给坐标是**取该坐标之前最近的那个检查点**——如果那个位置本身没建检查点，落到它前面的等待点。找不到报 `rollback-target-not-found`「坐标之前没有检查点：(columnId, index)」；下标越界报 `rollback-target-out-of-range`「检查点下标越界：N（共 M）」。

故事没启动，或者上一次回溯还没走完就再调一次，报 `rollback-invalid`「故事尚未启动」和 `rollback-in-progress`「回放进行中，拒绝重入」。

## 前进

```ts
engine.forward();
```

回到最新处还按，报 `no-forward`「没有可前进的历史（已在最新处或时间线已分岔）」。

「已分岔」是这么回事：你退回第 5 个检查点，然后选了另一个选项。引擎从这里往下记新历史，原来的第 6、7、8 个检查点被截断——那条路你已经走掉了。

```text
检查点: 0 1 2 3 4 [5] 6 7 8      ← 退到 5，光标停在 5
检查点: 0 1 2 3 4 [5] 6'         ← 选了另一个选项，6 7 8 被砍掉
```

检查点总量有上限，默认 200 个。满了从最旧的一端丢，玩家退不到更早的地方。

## 什么跟着回退

| 内容 | 回退后 |
|---|---|
| 全局变量 | 回到检查点那一刻的值 |
| 随机数状态 | 回到那一刻的种子，重放抽到同一串数 |
| 函数表 | 回到那一刻 |
| 舞台元素 | 回到那一刻的整棵树 |
| 块级、列级变量 | 不存，重放时按同样的代码重新声明 |
| 小游戏、交互系统 | 收到 abort 信号，立刻收尾 |
| 正在跑的 `wait` 计时 | 清掉，重放时重新计时 |

最后两行是回溯最容易出问题的地方：不打断的话，回溯之后旧的小游戏还在后台跑，计时器醒来还会去改已经回退掉的状态。引擎把这两件事在回退前做了。

## 历史面板要的数据

```ts
engine.historyView();
// [{ index, coord, speaker, text, nvl, nvlLines }, ...]
```

每一项对应一个检查点。`speaker` 和 `text` 是那一刻画面上的人和话；`nvl` 标记它是不是 NVL 全屏模式，是的话 `nvlLines` 带当时累积的整块文本。做对话记录面板直接用这个，不用自己存。

## 报错对照

| 错误码 | 消息 | 什么时候 |
|---|---|---|
| `rollback-invalid` | 故事尚未启动 / 当前不可回退 / 当前不可前进 | 没 `start()`，或者重放还没结束 |
| `rollback-in-progress` | 回放进行中，拒绝重入 | 上一次回溯没走完又调了一次 |
| `rollback-target-not-found` | 坐标之前没有检查点：(columnId, index) | 用坐标定位，前面确实没有检查点 |
| `rollback-target-out-of-range` | 检查点下标越界：N（共 M） | 下标超出范围 |
| `history-empty` | 已回溯到最早保留点 | 已经退到头了 |
| `no-forward` | 没有可前进的历史（已在最新处或时间线已分岔） | 没有前向可走 |

这些错误都从 `engine.error` 事件出来，`code` 是上表第一列。玩家点了个没用的按钮，界面不该崩——把提示显示出来就行。
