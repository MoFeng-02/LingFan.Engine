## v0.7.3

2026-11-23 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.7.3)

### 修复

- **脚手架生成出来的工程开箱就是类型错误的**：用已发布的 `create@0.7.2` 生成工程后跑 `typecheck`，vue、react、小程序三种形态全红。根因三个——vue 层组合根漏交 `minigame` 挂载槽（`StageDom` 里它是必填，`| null` 说的是「本层可以不提供这个槽」，不是「字段可以省」）；react 层的 `src/main.tsx` 被骨架自带的 `src/main.ts` 遮蔽（同目录同 basename 时 TypeScript 只收 `.ts`，而 `index.html` 加载的正是 `.tsx`），于是它从未进过类型检查、错得一干二净还显示通过；小程序层则是 `ref` 把 class 实例包成响应式代理丢私有字段、`as const` 常量推出字面量类型、以及 `<switch>` 与 SVG 元素同名导致 `@change` 载荷类型对不上。四处全部修好，四形态真生成实测零错误。
- **react 形态补摘骨架入口**：react 叠加层现在显式摘掉骨架的 `src/main.ts`，让 `main.tsx` 成为唯一入口——这是「同名遮蔽」的结构性修法，不靠改名绕开。
- **英文投影按当前源码重新对账**：此前是照着陈旧键表译的，译完仍报缺译 54 条。改为先取当前源码键集合、再取缺译清单求差集，清掉陈旧键、补齐真缺译；`main.json` 一并补上宿主面板文案。

### 新增

- **CI 真查「已发布版本能不能撑起当前模板」**：包管理器矩阵此前已装 registry 上的已发布包，却只跑 `stories:build` 与 `build`——而 vite 只转译不做类型检查，所以「源码里有新 API、registry 还没发布」这一类问题它一律看不见。现在补跑 `typecheck`，并在打包之前跑。
- **CI 按形态真生成再验**：新增作业覆盖 vue、react、小程序、桌面壳四种组合，每格都真生成工程、真装依赖、真跑类型检查；同时断言入口文件确实在类型检查范围内——专门用来抓上面那种遮蔽。
- **模板版本声明互锁判据**：`minEngineVersion` 必须等于各引擎依赖区间的下界、也等于仓库根版本；叠加层用到的 `PlayerPreferences` 成员必须真实存在于引擎源码。这两条以前纯靠人守，漏了不会红。

### 其他变更

- **模板版本**：`1.28.0` → `1.31.0`（`1.29.0` 阅读速度档接线、`1.30.0` 框架叠加层句柄、`1.31.0` 小程序类型面与形态矩阵）。
- **演练场英文投影**：宿主面板全部文案过文案门面，`main.json` 从 48 键扩到 105 键。

## v0.7.2

2026-11-22 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.7.2)

### 新增

- **自动播放按句长分摊停留时长**：此前每句都卡同一个固定时长，长句还没读完就翻页、短句又要干等。现在每句的实际停留 = 基础停留 + 该句词元量 ÷ 阅读速度，长句停得久、短句停得短。新偏好 `autoReadCps`（词元/秒，缺省 12，值域 1–200，下限不为 0——它是除数，取 0 会让停留变成无穷）配 `setAutoReadCps` / `clearAutoReadCps`；`autoDelayMs` 的语义收窄为「基础停留」。词元口径：中日韩字符各计 1，拉丁与数字的连续串计 1，空白、标点与内联标记不计。偏好面板与设置面板同步加了「阅读速度」滑杆。
- **渲染层导出词元量与停留计算**：`countReadingTokens` 与 `autoDwellMs` 以纯函数形式导出，宿主可复用同一套口径；`Typewriter` 新增 `readingTokens`，`TypewriterReader` 读面新增可选的 `readingTokens`——**做成可选是有意的**：早期宿主的旧实现不会因为多一个必填字段就编译不过，缺省时自动退回按引擎正文现数。

### 修复

- **字体名白名单放行连字符与点**：此前白名单只认 `\w` 与中文，而仓库里的真实字体名形如 `SourceHanSerifCN-VF`，一律被判非法并静默回退默认字体——`{font=}`、逐句字体、玩家字体偏好三处会同时失效且不报错。字体族投影补上注册表校验后再落到 CSS 变量，未注册的字体名 fail-closed 回退。
- **模板字体档从禁用占位变为活控件**：字体选项来自构建期扫描的清单，选中值经注册表校验后投影；模板同时装配了字体名注册表，让 `{font=}` 与玩家字体偏好在脚手架产物里也走同一条校验。

### 其他变更

- **模板版本**：`1.26.0` → `1.28.0`（`1.27.0` 为字体链与偏好三 setter 接线，`1.28.0` 为播放节奏接线），`minEngineVersion` 从 `0.5.0` 抬到 `0.7.1`——原值早就低估了：模板调用的 `setDialogueHeightScale` 等 API 在 0.5.0 里根本不存在。
- **模板依赖区间**：`^0.4.0` → `^0.7.1`，一次对齐到当时版本。

## v0.7.1

2026-11-22 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.7.1)

### 新增

- **字体注册表递归扫描子目录**：字体按分类分目录（`OTF` / `TTF` / `WOFF2`）是常规形态，此前只扫 `Resources/Fonts/` 顶层，子目录里的字体一个都进不了注册表——字体下拉因此长期是死控件。现在逐层下探，`file` 从「纯文件名」改为「相对字体根的路径」，宿主据此拼资源 URL。同族不同格式（`.otf` 与 `.ttf` 同名）可以共存，宿主为每个文件各注一条 `@font-face`，浏览器按自身支持的格式择优。
- **偏好补齐自动播放与快进三处 setter**：`setAutoEnabled` / `setAutoDelayMs` / `setSkipUnseenOnly` 进 `PlayerPreferences`，播放节奏从「宿主自己想办法」变成引擎能力。
- **模板播放节奏接线**：自动播放、自动延时、快进只走已读三项从禁用占位改为活控件，由宿主节奏循环实时读。
- **演练场门面**：启动页补齐语言切换与续玩摘要、工具条 Auto / Skip 变可见活控件、开场改为叙事序幕、新增功能演示章（已读快进、音频多实例、不可回溯段、小游戏与交互分流）与六种表情差分立绘、新增 PixiJS 实时渲染场景列作为列身体组件。

### 优化

- **`.story` 写回口径定案**：存储恒为 JSON，`.story` 的文本形态是创作输入格式，保存即规范化；路径保原样（`.story` 写回 `.story`），形态判定按内容首字符分流。此前测试里「文本形态逐字节不变」的断言前提与这条设计相反——文本投影会丢注释、把 `define` 提到文件头，做不到字节幂等，也不该做。断言改为按形态分桶：JSON 形态逐字节不变，文本形态断言差异集恰为这些文件、写回后重新组装与原 story 深等、无删除、文件集不变。
- **字体类型面按字体名去重**：同一款字体常以多种格式分发，注册表为每个文件各记一条，而类型面的键是字体名——不去重会让同一键重复成多行。

### 其他变更

- **门禁**：prettier 显式忽略会话产物元数据目录（它只被 `.git/info/exclude` 本地排除，prettier 不读那个文件）。
- **英文元素页**：描述里的冒号加引号，修复 frontmatter 的 YAML 解析失败。

## v0.7.0

2026-11-21 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.7.0)

### 新增

- **玩家偏好成为引擎能力**：音量、文本速度、打字机、对话框的透明度/位置/高度/字号、元素填充默认值、键位、屏幕方向、全屏、字体档这些设置，此前各宿主各写一套；现在引擎给出 `PlayerPreferences` 契约与三态消费链（偏好 > 故事 > 内建），宿主只负责面板，改动即刻生效。故事里写的默认值成为「玩家没表态时」的那一层，玩家表过态就不再被故事覆盖。
- **机器级已读记录与快进 / 自动播放**：已读记录独立于偏好、存档与故事状态存在——跨存档共享、删档不清、不进快照。这是「已读」该有的语义：读过就是读过，不该因为读了个旧档又变回没读。快进与自动播放走和玩家点击完全相同的推进接缝，所以回溯期禁推进、界面场景让位、故事级不可跳过闸门、未读即停这些约束自然成立；模式本身是会话态，读档与回溯都不残留。
- **回退控制面**：装配期 `rollbackEnabled` 总开关（缺省 `true`，现行为不变）、会话态临时锁 `SYS.rollbackLocked`（进快照不进存档）、以及 `block_rollback` / `fix_rollback` 两个 op，让作者能在段级标记「这段不许回溯」。不可回溯时不建检查点，存读档照常。另新增工程作者级的 `historyLimit`，非法值降级默认并给诊断；读档时逐条覆盖历史检查点，迁不动就截断并告知。
- **宿主能力改为装配期纯数据声明**：`HostInfo.capabilities` 可选只增。身体组件声明它需要什么能力，宿主没声明就诊断并停止渲染——不做静默降级，因为降级出来的画面比报错更难查。能力比对只读两份纯数据清单，不探测平台。
- **安全面**：资源 DEK 获取从写死终局改为端口 + 适配器接缝，默认仍是包内 seed（口径诚实标注 casual 级——seed 明文随包，不承诺无法提取），未来换更强的供给方式不必动密码学核心。存档写档头部升级为加密认证（模式、计数、时间戳纳入认证，篡改即失败，旧档仍可读）；存档、高水位、偏好、持久化统一原子写（临时文件 + rename，崩溃不留半档）；iOS Keychain 标记仅本机解锁后可用，KEK 改短 TTL 按需重取、取用副本用后清零。桌面壳 CSP 收紧到最小权限（无 `unsafe-eval`），存档槽位校验 fail-closed，调试通道加来源白名单与令牌握手。
- **跨端**：小程序视频按真实舞台尺寸填充、实例层级以页面数据表达；模板与小程序的构建目标降到 safari13，旧 WebView 禁用清单守卫扩到这两处。
- **脚手架宿主接线补齐**：身体组件装配、偏好消费、输入面键位与滚轮 / Esc / 快速存读、启动续玩页、小游戏真挂载、扩展注册、屏幕方向与全屏策略下沉、小程序设置面板与无障碍。

### 优化

- **锚点互锁扩批**：行为已测的规约锚点署名入册（31 → 51），双向精确相等断言，互锁率只增。
- **契约层零实现依赖**：删掉契约出口对判定层的回边转发，消费方改直引。只变 import 路径，行为不变。
- **换列中断单一收尾**：进列与元素序列离列共用同一个中断函数，`jump` 直调不再漏掉外部接管信号。
- **检查点真提交才置位**：只有当检查点真的入档才置「已入档」标记，被守卫丢弃的一律不置位。
- **测试探针竞态**：锚点与故事源探针改为 per-test 临时副本隔离，真实工程树零写入，并行跑稳定。

### 修复

- **op 自洽**：新增 `audio_seek`（实例或通道二选一）；`audio_pause` / `audio_resume` 支持实例维度；`audio_volume` 扩到实例与通道目标。媒体族停止 / 暂停 / 恢复对齐；`video` / `cutscene` 同一资源默认续播、`restart` 才显式重播。
- **装载期校验**：23 + 1 个 op 补上解析层的 fail-closed 校验；扩展的 `stateVersion` 加整数校验；`character` / `nvl` / `video_skipable` 的宽松口径收紧；`text_typewriter` 合并写入时保留 `enabled`。
- **创作链类型面**：`label` 补列收集对齐列名收窄面——`option` 目标与 `navigate` 第二参也纳入收集，指向导出函数时补 `flow` 列；`call` 目标收窄为「已知列名或已知函数名」的联合，函数名表进编译期类型域。

### 其他变更

- **文档**：规约快照同步（op 全集 76 终态、五源相等）；英文文档从 15 篇真翻译 + 25 篇回退，补齐为 40 篇全真翻译（中英对账 40 = 40，无回退残留），技术术语（op 名、错误码、API、命令、字段名）一律不译；新增文档快照守卫测试，把规约与文档里的数字钉住，防止悄悄漂移。
- **模板版本**：`1.25.0` → `1.26.0`。模板内容有变（宿主接线补齐、身体装配、安全策略），因此抬版本号；引擎版本线独立。

## v0.6.0

2026-11-18 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.6.0)

### 新增

- **脚手架宿主接入多语言**：脚手架自带的宿主（原生 / Vue / React 三形态）与小程序形态都接上了译文供给与页面语言选择器——译文表放进 `Resources/Lang/` 即生效，工具条、存档标签这类宿主静态文案随语言切换重画，偏好与历史面板同步换语言。语言清单来自构建期扫描，加语言目录不必改名单；工程自带一份英文示例译文表。用法见[制作多语言工程](/guides/i18n/)。
- **命令行工具链 `lingfan-i18n`**：四个子命令——`scan` 键清单、`skeleton` 生成/更新译文骨架（幂等增量）、`report` 单语言对账、`check` 对账加退出码门禁（`--fail-on=missing|unused|any`，可直接接 CI）。支持 `--functions` 登记翻译函数别名、`--json` 机器可读输出、`--prune` 清理无源孤儿键。详见[制作多语言工程](/guides/i18n/)。
- **宿主门面 `createHostI18n`**：`@lingfan-engine/shell` 新增门面工厂，把宿主界面文案接到引擎同一条译文供给上——`t()` 查表、`changeLang()` 切语言、`subscribe()` 订阅语言变更、`availableLangs` 供选择器取列表。工厂而非单例，门面不持有译文表。API 与接法见[多语言与译文](/concepts/i18n/)。
- **通知中心与选项视图的可本地化注入口**：两者新增可选 `translate` 注入（通常传 `engine.translate` 或门面的 `t`），注入后组件内置的玩家可见文案（如「已存档」、输入框的「确定」）也走译文表；不注入则行为与旧版完全一致。旧的 `texts` 文案键保留，作未命中回落与宿主改写入口，已标记弃用、将在后续版本移除。
- **翻译体检新增两类诊断**：**宿主未标记文案**（宿主源码里含中文却没包 `t()` 的字面量，逐条给文件与行列位置）与**布局冲突**（同一语言下同键多文件取值不一，后写胜会静默遮蔽）。体检的比对面同时扩到宿主静态文案键。

### 行为变化

- **界面文件不再支持 `.html`**：界面文件必须是能被默认导入的模块，而 HTML 不是 ES 模块，装不进这条通道。此前构建期不报错、直到运行时才说「界面没挂上」，白等一场；现在构建期直接拒绝并说明该改用什么。已有 `.html` 界面请改写为 `.vue` / `.tsx` / `.ts` 之一。
- **存档与状态存原文，不再存译文**：对话、菜单、输入、NVL、元素文字在状态容器、快照与存档里统一存原文，译文在读的那一刻按当前译文表派生。切换语言后**当前画面立即重译**（含屏幕上的元素文字与历史面板）；读档后显示什么语言取决于读档时的语言设置。存档格式（`SaveDataV1`）字段集合不变；旧版本存档里存的是译文，读入时引擎把疑似译文的字段在内存里标记、跳过查表，避免拿译文当原文二次误译，引擎重写该字段后标记即清——老档自动降级，无需迁移。
- **已知边界：含 `{变量}` 的句子，翻译对象是模板**：说话人名与正文里的插值句，查表用的是原文模板（如 `你好，{name}！`）而不是插值后的结果；派生时先取模板译文，再把当时捕获的变量值插回去。变量值本身不翻译。

### 优化

- 切换语言后当前画面（对话、说话人、菜单、输入、NVL、元素、历史面板）立即重译生效，帧栈深度与列坐标不变、不重放。

## v0.4.0

2026-11-09 · [完整说明与提交清单](https://github.com/MoFeng-02/LingFan.Engine/releases/tag/v0.4.0)

### 新增

- **舞台适配：`shell.stage` 成为可移植的契约**：设计基准、缩放策略、对齐与上下限下沉到 `@lingfan-engine/core` 的契约与解析器，`@lingfan-engine/shell` 出纯计算件 `computeStageLayout` / `stageTransform` 与编排件 `createStageFitter`。宿主只提供「读视口、写样式」两个平台动作，计算里不读任何平台全局，桌面壳、浏览器与小程序共用同一份口径。
- **模板宿主接入舞台适配**：脚手架自带的宿主（原生 / Vue / React 三形态）现在真的读 `shell.stage`——基准像素构图在任意窗口比例下等比缩放，宿主 UI 留在窗口坐标系里不跟着缩放。此前这条配置在模板上是「写了不生效」。
- **图像填充中立词表**：图片、图片按钮、立绘、视频、背景五类元素共用一个 `stretch` 属性，值域收成五个词（`fill` / `contain` / `cover` / `none` / `scale-down`），与 CSS `object-fit` 对齐但不逐字相同。三端各自映射：浏览器写 `object-fit` 或 `background-size`，小程序按平台只有三个值的能力退化，编辑器出下拉框。引擎只存词，不存 CSS 字符串。
- **编辑期诊断 `invalid-element-fit`**：`stretch` 写了词表外的值会退到缺省值，同时在诊断面板报一条 warning，不再静默。

### 行为变化

这几条会改变已有工程的画面，升级前值得看一眼：

- **未写 `stretch` 的图片从「原尺寸」变成「铺满裁切」**：此前图片元素不产出任何 `object-fit`，浏览器按默认行为显示；现在缺省是 `cover`。作者坐标系的框与图片比例不一致时会看到裁切（此前是拉伸或留白，视元素类型而定）。想保持原样就给元素写 `stretch="contain"` 或 `stretch="none"`。
- **背景元素从「看不见」变成「铺满舞台」**：背景元素此前是一个没有宽高的 `div`，`background-image` 无处可铺；现在引擎把它的框写成 `100% × 100%`（舞台那么大），图片按缺省 `cover` 铺满。这是本版最想要的效果，但它意味着所有用 `background` / `bg_switch` 的历史工程画面会变。
- **视频缺省填充从 `contain` 变成 `cover`**：此前视频端口把 `object-fit: contain` 硬写进样式表，非 16:9 的窗口里上下留黑边；现在按元素声明走，缺省 `cover` 铺满并裁切。要去掉裁切就给视频元素写 `stretch="contain"`。

### 优化

- **模板宿主的舞台分层**：`#stage-root` 从 `fixed` 改成 `absolute`（挂在 `#stage-viewport` 里），屏幕震动从舞台根搬到中间层 `#stage-shake`——缩放写在舞台根、震动写在内层，两者不再互相覆盖。
- **模板宿主 UI 尺寸改成响应式**：对话面板、选项、通知、工具栏、错误提示的位置与字号从固定 px 改成 `clamp()`，小窗口下不再溢出或被截断。舞台元素层（`#stage` / `#stage-root` / `#stage-shake` / `#stage-viewport`）保持基准像素口径，一条 `clamp()` 都不写——那里必须由缩放统一负责。
- **模板副本一致性纳入门禁**：`template/v1` 与 `packages/create/template` 两棵树的文件清单与内容逐字节比对进测试，改一边忘另一边会直接红。

### 修复

- **`stretch` 此前是空表单**：契约里声明了、编辑器也给了表单，但渲染层零消费——写了完全没效果。本版把它接进渲染层，`stretch="cover"` 这类值从此真的生效。

### 其他变更

- **文档**：`shell.stage` 的「模板还没接」说法去掉；元素一章新增「媒体填充」小节，讲清五个词、三端映射与两处平台退化；模板能力边界表把「舞台适配」从「没接」移到「接了」；新增[屏幕适配](/guides/screen-adaptation/)专题，从「我的游戏怎么同时适配手机和大屏」入手讲三套坐标系、基准配置与宿主接法。
