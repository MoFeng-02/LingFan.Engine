灵泛引擎把「故事」和「画面」拆成两件事。故事是指令序列，引擎负责执行；画面是 DOM，由你写的宿主决定怎么渲染。引擎核心不 import 任何 UI 框架、Tauri API 或 Node 内建模块——这条边界由 lint 规则守着，不是口头约定。

## 能力

<CardGrid>
  <Card title="写故事就是写指令" icon="open-book">
    故事由若干列组成：`label` 是流程列，`scene` 是空间列，列里排的是 `say` /
    `menu` / `if` 这样的指令。文本形态是 JSON v1
    的投影，两种文件在同一个工程里混存合法。
  </Card>
  <Card title="66 个内建 op" icon="list-format">
    从 `say`、`menu` 到 `save`、`bgm`、`video`、`minigame`，按 9
    个域分页收录在参考区。op 名写错不会静默跳过——引擎停在
    `unknown-op`，并告诉你卡在哪一条。
  </Card>
  <Card title="36 种舞台元素" icon="puzzle">
    `text`、`image`、`portrait`、`panel`、`grid`、`scrollviewer`、`slider`……元素可以嵌套。层级
    z 由 `project.json` 解析后写入，不在样式里写死。
  </Card>
  <Card title="回溯到任意一步" icon="clock">
    引擎保留历史游标，`back()` / `forward()` / `rollbackTo()`
    直接跳。存档也是普通指令（`save` / `load` /
    `auto_save`），槽位数与缩略图开关写在工程清单里。
  </Card>
  <Card title="多语言不是外挂" icon="translate">
    `Resources/Lang/{lang}/` 放译文覆盖表，`setLanguage()`
    切换。没写译文的条目原文直出，不会渲染成空白。
  </Card>
  <Card title="换框架不用动核心" icon="code-branch">
    核心包不依赖 Vue、React 或 Tauri。脚手架模板的宿主是零框架的纯 DOM
    实现——想换成 Vue / React，改的只有 `src/main.ts` 和 `index.html`。
  </Card>
</CardGrid>

## 三步跑起来

<Steps>

1. 在仓库根装依赖。

   ```bash
   pnpm install
   ```

2. 起参考宿主。

   ```bash
   pnpm dev
   ```

3. 打开终端打印的地址（默认 `http://localhost:1420`），点击或按空格推进对话。故事文件在 `Resources/Stories/` 下，媒体放 `Resources/{Audio,Images,Video}`。

</Steps>

想从零建自己的工程，看[从模板创建工程](/from-template/)；想知道每个 op 接受哪些参数，看 [op 指令参考](/reference/ops/)。
